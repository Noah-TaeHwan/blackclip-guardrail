# 공개 샘플 데모 (guardrail.blackclip.app)

지어낸 전략 넷으로 그린 읽기 전용 대시보드와 첫 장을 정적 파일로 만들어요. 실제 거래소 · 키체인 · 텔레그램에는 닿지 않아요.

- `sample.py`: 지어낸 레포를 만들어요. 같은 커밋에서 두 번 만들면 바이트가 같아요. 만드는 동안 가짜 `security`를 PATH 맨 앞에 두고, 한 번이라도 불리면 빌드가 멈춰요.
- `build.py`: 홈부터 렌더러가 낸 상대 링크를 따라가며 모든 화면을 정적 모드로 그려요. 토큰 · 폼 · 연결 화면 · 내보내기 단추는 없고, 대시보드 9쪽 맨 위에 샘플 띠가 붙어요.
- `site/`: 호스팅 파일(`wrangler.jsonc` · `_headers` · `_redirects`). 빌드가 그대로 복사해요.

## 빌드

```bash
demo/build.sh <site 폴더>
```

데모 시험(골든 · 샘플 · 정적 모드 · 빌드)이 모두 통과해야 `<site>/wrangler.jsonc`와 `<site>/dist/`를 써요. 쓰는 파일은 첫 장 `dist/index.html`, 샘플 대시보드 `dist/demo/**`(9쪽), `dist/_headers`, `dist/_redirects`예요.

다 쓴 뒤 만든 쪽 10장의 원문(소스 보기 · CSS 포함)에 내부 표지가 하나라도 있으면 종료 1로 멈춰요(`tests/test_customer_copy.py`와 같은 검사).

## 배포

배포는 이 스크립트가 하지 않아요. 빌드 끝에 찍히는 명령(`wrangler deploy -c <site 절대 경로>/wrangler.jsonc`)을 BlackClip 계정의 wrangler로 어느 폴더에서든 그대로 돌려요. 첫 장의 GitHub 링크와 설치 명령은 레포가 공개돼야 살아서, 배포는 레포 공개 직후에 해요.

루트 `/`는 첫 장이에요. 예전 데모에만 있던 쪽 7개(연결 쪽, 지금 샘플에서 뺀 전략 셋의 가드레일 · 회고)는 슬래시가 있든 없든 첫 장으로 301 보내요. `_redirects`는 같은 경로에 파일이 있어도 이기므로(Cloudflare Workers 정적 자산 문서), 지금 있는 쪽을 덮는 줄이나 별표 줄은 두지 않아요. 시험이 이 둘을 막아요.

## 확인 (2026-10-22, 코드 이 브랜치)

127.0.0.1 정적 서버가 `_headers` 값을 모든 응답에 붙이고, Playwright 1.63.0(Chromium · WebKit 2359)으로 10쪽 × 390 · 1440을 쟀어요(40번).

| 항목 | 기준 | 결과 |
|---|---|---|
| 문서 가로 넘침 · `.scroll` 밖 화면 밖 요소 | 0 | 40/40 0 |
| 글자 대비 최저 | 4.5 이상 | 8.35 |
| 누름 상자(글 속 링크 제외) | 44 이상 | 40/40 44 이상 |
| 샘플 띠 높이 / 첫 화면 | 25% 이하 | 390: 12.9%, 1440: 6.8% |
| 차트 SVG | 서버 화면과 같음 | 9쪽 81개 바이트 같음 |
| 콘솔 오류 · CSP 위반 · 4xx | 0 | 40/40 0 |

- 같은 샘플을 이전 내보내기 방식으로 그린 것과 견주면, 쪽 집합 · 쪽마다 링크 집합의 차이는 연결 쪽 1장과 메뉴 「연결」뿐이에요.
- WebKit은 Safari의 엔진이지만 실제 Safari와 같지 않아요(글꼴 렌더링 · 스크롤바 · 확대 설정). 실제 Safari 확인은 따로 해요.
